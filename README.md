# cheatsheet-template

> A reusable LaTeX template for compact, multi-column cheat sheets in landscape A4 format.

## ✨ TL;DR
```bash
pdflatex "Template Cheatsheet.tex"
```

## 🚀 Features
- **Multi-column layout:** Optimized for high information density on a single A4 landscape page.
- **Color-coded sections:** Configurable colors for titles, sections, subsections, and formulas.
- **Math support:** Full support for mathematical formulas via AMS packages.

---

## 🛠️ Installation

### Prerequisites
- LaTeX distribution (e.g., TeX Live, MiKTeX)
- PDF viewer

### Steps
1. Clone the repository:
```bash
git clone https://github.com/HuberNicolas/cheatsheet-template
cd cheatsheet-template
```
2. Compile the template:
```bash
pdflatex "Template Cheatsheet.tex"
```

---

## 💻 Usage

Open `Template Cheatsheet.tex`, customize the content, and recompile. Alternatively, import it into Overleaf and edit directly in the browser.
